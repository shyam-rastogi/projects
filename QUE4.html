Python Tutorial

Lesson 1: Print

The print() function shows text on the screen.

print("Hello World")

Output: Hello World

Lesson 2: Variables

A variable stores a value.

name = "Asha"
age = 19
print(name, age)

Output: Asha 19

Lesson 3: Loops

A for loop repeats code.

for i in range(3):
    print("Hello", i)

Output: Hello 0, Hello 1, Hello 2

Lesson 4: Functions

A function is a block of code you can use again.

def square(n):
    return n * n

print(square(5))

Output: 25
